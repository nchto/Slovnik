# Словник

Флешкарты для заучивания слов по алгоритму интервальных повторений Anki. Работает в браузере и устанавливается на телефон как приложение.

- Импорт колод Anki (`.apkg`, `.colpkg`) вместе с прогрессом, а также `.txt`, `.csv`, `.tsv`.
- Параметры изучения для каждой колоды: порядок новых слов (по порядку или вразброс), порядок повторений, лимиты на день, шаги изучения, алгоритм SM-2 или FSRS-6, трудные слова.
- Словарь всех слов со статусами, поиском и карточкой слова: прогресс, вероятность вспомнить, формы английского глагола во всех временах, значения и примеры из Викисловаря.
- Тесты: выбор ответа (в том числе на скорость), ввод перевода, поиск пар; можно тренировать только трудные слова.
- Арабский: шрифты Noto Naskh Arabic, Amiri и Scheherazade New, настройка огласовок (показывать, скрывать в вопросе, скрывать везде), транслитерация по огласовкам, проверка ответа без учёта огласовок и написания хамзы, экранная клавиатура с харакатами, арабская озвучка, корень, множественное число и таблицы из Викисловаря.
- Аккаунт: колоды и прогресс синхронизируются между устройствами через Supabase.
- Резервная копия всех колод с прогрессом в один файл `.json`.

## Как устроено

Это статический сайт без сборки: `index.html`, `core.js` (алгоритм, импорт), `ui.js` (интерфейс), `cloud.js` (вход и синхронизация), `config.js` (адрес и публичный ключ Supabase). Библиотеки лежат в `vendor/`.

Данные хранятся в одной таблице `docs` в Supabase. Каждая строка принадлежит одному пользователю, а правило доступа (Row Level Security) не даёт никому, кроме владельца, прочитать или изменить её. Большая колода хранится в нескольких строках примерно по 150 КБ, поэтому её размер не ограничен.

## Настройка

1. Создайте проект на [supabase.com](https://supabase.com) (бесплатный тариф).
2. Откройте **SQL Editor**, вставьте содержимое `supabase-schema.sql` и нажмите **Run**.
3. В **Authentication → URL Configuration** укажите в **Site URL** адрес сайта, например `https://<логин>.github.io/Slovnik/` (регистр букв как в названии репозитория), и добавьте его же в **Redirect URLs**.
4. Если пользоваться будут не только участники проекта Supabase, выключите подтверждение почты: **Authentication → Sign In / Providers → Email → Confirm email**. Встроенная почта Supabase отправляет письма только участникам команды проекта. Чтобы письма (подтверждение, сброс пароля) доходили всем, подключите свой SMTP в **Authentication → Emails → SMTP Settings**.
5. Скопируйте `config.example.js` в `config.js` и впишите **Project URL** и публичный ключ (`anon` или `publishable`). Секретный ключ (`service_role` или `secret`) сюда вставлять нельзя.
6. Включите GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.

Если `config.js` пустой, приложение работает без аккаунтов и хранит колоды в браузере.

## Ограничения бесплатного Supabase

- База данных до 500 МБ. Этого хватит примерно на миллион карточек.
- Проект ставится на паузу после 7 дней без запросов. Данные сохраняются, а проект включается кнопкой **Restore** в панели Supabase.
- Встроенная почта Supabase отправляет лишь несколько писем в час. Для одного человека этого достаточно.
