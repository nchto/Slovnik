# Словник

Флешкарты для заучивания слов (в первую очередь арабский, также английский) по алгоритмам Anki: SM-2 и FSRS-6.
Владелец и его друзья пользуются сайтом https://nchto.github.io/Slovnik/ (GitHub Pages из ветки `main`, корень репозитория).
Интерфейс и все тексты на русском. Отвечать владельцу по-русски, цены всегда в рублях, сложное объяснять через аналогии.

## Где что лежит

- `core.js` — логика без интерфейса: планировщик (SM-2, FSRS-6), очереди, импорт Anki/CSV, проверка ответов,
  арабский (огласовки, транслитерация, нормализация), английские формы глаголов, разбор Викисловаря, цитаты.
- `ui.js` — весь интерфейс и хранилища: локальное (IndexedDB с журналом в localStorage) и облачное
  (документы, разложенные по «пачкам» до 150 КБ).
- `cloud.js` — вход по почте и паролю и синхронизация через Supabase (одна таблица `docs`, доступ по RLS).
- `tools/shell.html` — разметка и все стили (CSS-переменные для светлой и тёмной темы).
- `tools/build.py` — собирает `index.html` (сайт) и `tools/artifact.html` (версия для claude.ai со встроенными скриптами).
- `config.js` — адрес проекта Supabase и publishable-ключ (публичный, его можно хранить в репозитории).
- `supabase-schema.sql` — схема базы. Её выполняют вручную в Supabase SQL Editor.
- `sw.js` — офлайн-кэш. После любого изменения кода поднимать `VERSION`, иначе телефоны получат старую версию.
- `.github/workflows/keepalive.yml` — каждые 3 дня вызывает `keepalive()`, чтобы бесплатный Supabase не засыпал.
- `vendor/` — JSZip, fzstd, sql.js (asm), supabase-js. Грузятся с сайта, без внешних CDN.

## Как вносить изменения

1. Править `core.js`, `ui.js`, `cloud.js`, `tools/shell.html`.
2. `python3 tools/build.py`, затем поднять `VERSION` в `sw.js`.
3. Проверить в браузере (Playwright с Chromium уже установлен): поднять `python3 -m http.server` в корне и пройти
   затронутые сценарии. Обязательно проверить сохранение после перезагрузки, арабский текст, тёмную тему и ширину 390 px.
4. Коммит в `main` и push: сайт обновится примерно за минуту.
5. Версия на claude.ai (https://claude.ai/artifact/WWwwZENstcocY5LYbRmQZe) публикуется отдельно из `tools/artifact.html`.

## Правила

- Данные пользователей живут в Supabase. Изменения формата хранения должны читать старые данные
  (`deserialize` и `cardFromRow` в `core.js` терпят отсутствующие поля). Новые поля карточек добавлять в конец `CARD_KEYS`.
- Секретный ключ Supabase (`secret` / `service_role`) никогда не хранить в репозитории и не просить у владельца в чате.
- Встроенная почта Supabase шлёт письма только участникам проекта, поэтому подтверждение почты выключено,
  а сброса пароля по почте нет.
- Страница «Разбор фраз» (https://claude.ai/artifact/DLRiJ4GpygqzkwUEHBwkc7) пока черновик: владелец просил её не развивать.
